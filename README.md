# Naveen Gupta — Academic Website

A responsive academic website for GitHub Pages. No installation or build required.

## Edit your website

Edit `dist/index.html` to replace the text in square brackets with your academic title, institution, biography, research areas, publications, courses, and contact details. Edit `dist/style.css` to change the design. The abstract artwork uses CSS and needs no image files.

To add a CV, put `cv.pdf` in `dist/` and add a link to it in `index.html`. To add an email link, replace the contact placeholder with `<a href="mailto:you@example.com">you@example.com</a>`.

## GitHub Pages

The website source is uploaded to `naveenkgupta699/naveen_gupta.maths`. Under Settings → Pages, select Deploy from a branch, choose `main` and `/ (root)`, and save. Your site will be at `https://naveenkgupta699.github.io/naveen_gupta.maths/` after GitHub deploys it. Edit `index.html` in the repository to customize your content.

Google Fonts are optional; local serif and sans-serif fallbacks are provided.
